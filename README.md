I'm a B.Tech student in **VLSI Design** at **MIT Bengaluru (MAHE)**, class of 2028, and Tech Lead of the **VED** (VLSI & Embedded Design) club.
I like working where disciplines collide: interfaces that move (React, GSAP, an unhealthy respect for easing curves), machine learning that has to answer to the hardware it runs on, and silicon-level ideas like compute-in-memory. All of it happens on Arch, btw.
